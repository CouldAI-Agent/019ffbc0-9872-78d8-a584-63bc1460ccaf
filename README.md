# El Sombrero del Abuelo Antonio

Una aplicación de cómic interactiva estilo "grabado mexicano" construida con Flutter. La aplicación presenta la historia de Samuel y el sombrero mágico de su abuelo Antonio, ilustrada con una estética monocromática inspirada en la técnica del grabado en linóleo.

## Características
- **Estética de Grabado Mexicano**: Diseño visual en blanco y negro, con texturas de alto contraste y tipografía que recuerda al grabado tradicional.
- **Cómic Interactivo**: Paneles de cómic de desplazamiento horizontal.
- **Responsive**: Se adapta tanto a pantallas móviles (vista apilada por paneles) como a tabletas/escritorio (lista de desplazamiento horizontal).
- **Historia Completa**: Incluye la narración completa de la historia del sombrero del abuelo Antonio.

## Ejecución
Para ejecutar esta aplicación, asegúrate de tener Flutter instalado y configurado.

```bash
flutter pub get
flutter run
```
